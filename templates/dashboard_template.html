Resolution 35 network tables

ITU Space Network List milestones and the satellites reported in each milestone PDF. Hover a column name for its meaning. Hover an underlined value for the PDF and the network's ITU Space Explorer page.

About the Space Explorer links. The number at the end of a Space Explorer address is an ITU notice ID. Each submission for a network (advance publication, coordination, notification, and the Res 49, Res 35 and Res 8 submissions) has its own. Network links here use the network's latest notification, or its latest coordination request when it has no notification, which matches the notice the Space Explorer shows for the network. br6a_br6b_id_no in the PDFs is the notification that applied when that PDF was submitted, so it can be older.
